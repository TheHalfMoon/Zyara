# Pilot clinic readiness checklist (M028)

English only. One signed copy per clinic before any service is enabled.

## Clinic identity

- [ ] Clinic legal name and branch address recorded
- [ ] Named verification owner (name, role, contact)
- [ ] Named reception owner (name, role, contact)
- [ ] Named escalation owner (name, role, contact)

## Per enabled service

- [ ] Service and appointment types configured per M009 onboarding
- [ ] Duration, buffers, resources, and authority recorded; M009 mandatory
      blockers cleared (missing duration/resource/authority blocks publish)
- [ ] Verification evidence checked per M008 (states attested/checked, not
      expired/withdrawn); badge scope matches checked facts
- [ ] Insurance acceptance is branch/network/service dated
- [ ] Intake and policy versions pinned

## Operating rehearsal (synthetic cases, no real records)

- [ ] Native instant booking rehearsed
- [ ] Request-mode scheduling rehearsed (deadline/owner explained)
- [ ] Closure/absence handling rehearsed (bulk preview with per-appointment
      outcomes)
- [ ] Changed-insurance case rehearsed (explicit next step, staff review)
- [ ] Attendance dispute rehearsed (independent review path)
- [ ] Cancellation with cutoff/assistance rehearsed

## Capability mode

- [ ] Full mode (native booking) or lower-capability mode assigned per
      `capability-modes.md`; unsupported clinics never display bookable hours
