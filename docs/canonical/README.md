This directory contains the canonical plan researched against live repository main `0c4d47bc61fabc3c4a657d44cb8c0f83156af744`, checked on 2026-09-13. This mission performed research and planning, not product implementation.

Start with the [master plan](ZYARA_CANONICAL_BUILD_PLAN.md) and its document map. Muse starts with [M001 in the execution handoff](ZYARA_MUSE_EXECUTION_HANDOFF.md). The set includes 13 canonical plans, 26 ADRs, 12 phases, 24 slices and 60 planned task contracts, with [planning validation](../research/PLANNING_VALIDATION.md) and [research evidence](../research/README.md).

The original files in `docs/` are the founder foundation and source-authorization record. They remain preserved. Explicit decisions in the converged canonical set supersede their implementation suggestions, but not founder constraints.
